An original spot-the-difference game that plays offline in a desktop browser from its own static files. Two panels show the same hand-drawn cove at dusk; the right one hides 8, 10 or 12 differences across three levels — a sun swapped for a moon, a lighthouse lamp gone out, a sail that grew stripes. Click a difference on either panel to ring it on both, ask for a hint when stuck (it costs ten seconds), and clear the cove before your misses pile up.

Everything is drawn and sounded in code: the scene is canvas art written for this game, the chimes are WebAudio tones, and no file loads over the network. Play it by serving `game/` from any static server and opening `game/index.html`.
